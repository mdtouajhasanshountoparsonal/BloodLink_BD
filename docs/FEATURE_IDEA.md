# BloodLink BD — ফিচার আইডিয়া বিশ্লেষণ: রক্তদাতা তালিকা (Open Roster)

> তারিখ: সেপ্টেম্বর ২০২৬ · Status: আলোচনাধীন

## আইডিয়াটা কী

অ্যাডমিন/ম্যানেজারের নিয়ন্ত্রণে একটি **রক্তদাতা তালিকা (bloodList)** থাকবে —
যেখানে নাম, **একাধিক নম্বর**, ইমেইল, এলাকা, রক্তের গ্রুপ যোগ হয়, আর **অ্যাডমিন নম্বর ভেরিফাই** করতে পারবে।
যেকোনো ইউজার তালিকা থেকে সরাসরি **কল / WhatsApp** করে যোগাযোগ করতে পারবে।

## ভালো দিক ✅

1. **জরুরি সময়ে দ্রুত সমাধান** — ম্যাচিং ছাড়াই নিশ্চিত "হ্যাঁ, দিতে পারবো" এমন মানুষের সরাসরি তালিকা।
2. **কম ঝামেলা** — নতুন ইউজার সাইন আপ/প্রোফাইল ছাড়াই নাম+নম্বর তালিকাভুক্ত হতে পারে (বয়স্ক ডোনার, গ্রুপ-ভিত্তিক)।
3. **ভেরিফিকেশন = আস্থা** — অ্যাডমিনের ভেরিফাইড ব্যাজ ফেক/পুরনো নম্বরের ভয় কমায়।
4. **একাধিক নম্বর + ইমেইল** — মোবাইল নম্বর বন্ধ থাকলেও ল্যান্ডলাইন/ইমেইল থাকে — যোগাযোগের সুযোগ বাড়ে।
5. **অ্যাডমিন/ম্যানেজার রোল ভাগ** — একা অ্যাডমিনের বোঝা কমে; ম্যানেজার তালিকা চালান, অ্যাডমিন ভেরিফাই করেন।

## খারাপ/ঝুঁকিপূর্ণ দিক ⚠️

1. **প্রাইভেসি লিক** — নম্বর পাবলিক হওয়ায় স্প্যাম/হ্যারাসমেন্ট/ফেক কলের ঝুঁকি। মানুষ নম্বর দিতে ভয় পাবে।
2. **স্প্যাম আক্রমণ** — ম্যানেজার/অ্যাডমিনের নম্বর বাদে সবার কাছে নম্বর খোলা = স্প্যামারের টার্গেট।
3. **ডুপ্লিকেট/অবৈধ এন্ট্রি** — ভুল নম্বর, নকল নাম, দ্বিগুণ এন্ট্রি — ডেটা নোংরা হতে পারে।
4. **ম্যানেজার লেভেল সিকিউরিটির দুর্বলতা** — ম্যানেজারের credentials হাতছাড়া হলে কেউ জাল এন্ট্রি বসাতে পারে।
5. **ফ্রি প্ল্যান সীমা** — bloodList সার্বক্ষণিক snapshots থেকে রিড বাড়ে; সীমা পেরোলেই দোষ পড়বে কোটা/Blaze-এ।

## সমাধান / সুপারিশ (যা ইতিমধ্যে নেওয়া হয়েছে বা নেওয়া উচিত)

| ঝুঁকি | ব্যবস্থা |
|---|---|
| স্প্যাম/ফেক কল | অ্যাডমিন **verified** ব্যাজ + রিপোর্ট সিস্টেম; ভেরিফাইড আগে সাজানো |
| প্রাইভেসি | শুধু সাইন-ইন ইউজার দেখতে পারে (rules); `showPhone`-এর মতো পছন্দ পরবর্তীতে |
| ম্যানেজার/অ্যাডমিন নিয়ন্ত্রণ | `appMeta/managers` + `admins` অ্যারে, rules-এ enforced; কেবল ম্যানেজার লিখতে পারে |
| ডুপ্লিকেট | নাম/নম্বর মিলিয়ে ম্যানেজার আসার সময়ে পরীক্ষা (ভবিষ্যতে) |
| কোটা | রিড অনুমান usage screen-এ; তালিকা বড় হলে শুধু verified দেখানোর টগল |

## রায় (verdict)

**মোটামুটি ভালো আইডিয়া — তবে "ওপেন রোস্টার" নয়, "মডারেটেড + ভেরিফাইড রোস্টার" হিসেবে।**
অ্যাপটির মূল শক্তি হলো অ্যাপ-ডোনারদের রিয়েল-টাইম ম্যাচিং; এই তালিকা সেটার **পরিপূরক** — বড় ব্লাড ব্যাংক/ল্যাব/অভিজ্ঞ ডোনারদের স্থায়ী ডিরেক্টরি।
সীমাবদ্ধতা: এই তালিকা যত বড় হবে, রিড কোটা তত বেশি খরচ হবে (Spark-এর ৫০,০০০/দিন) — তাই
তালিকা আইটেমের সংখ্যা সীমিত রাখা এবং ফ্রি প্ল্যানে এটা হিসেবে রাখা জরুরি।

### পাশাপাশি বিবেচনার টিপস
- ভবিষ্যতে বড় হলে প্রকাশ্যে **সরকারি রক্তদাতা কোড/ব্লাড ব্যাংক API**-এর সাথে যোগাযোগ করা ভালো — নিজের ডেটা ডিরেক্টরি গড়া ছাড়া।
- রোস্টারে **ব্লাড ব্যাংক/ল্যাব**ও রাখা যেতে পারে (প্রতিষ্ঠান প্রোফাইল), শুধু ব্যক্তি নয়।
- ইউজার চাইলে নিজেকে তালিকায় যোগ করুক — অথবা শুধু ম্যানেজার যোগ করুক — **বাটন দিয়ে ম্যানেজার যোগ করলে অ্যাডমিন ভেরিফাই করুক** এটাই পরিষ্কার ফ্লো।
