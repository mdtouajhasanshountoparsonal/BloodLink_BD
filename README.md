# BloodLink BD 🩸

বাংলাদেশের রক্তদাতাদের জন্য **ফ্রি ও ওপেন-সোর্স** ব্লাড-ডোনেশন অ্যাপ — ফ্লাটার + ফায়ারবেসে নির্মিত।

ভর্তি সম্ভাবনা দিন, জরুরি রিকোয়েস্ট করুন, কাছের কম্প্যাটিবল ডোনার খুঁজুন আর সরাসরি কল/WhatsApp-এ যোগাযোগ করুন।

## ✨ ফিচার
- 📍 লোকেশন-ভিত্তিক **কাছের ডোনার** তালিকা ও ম্যাপ
- ⚡ **স্মার্ট ম্যাচিং** — গ্রুপ/দূরত্ব/ভেরিফিকেশন/রেকর্ড স্কোর
- 🩸 জরুরি **রক্তের রিকোয়েস্ট** (জরুরি-ভিত্তিক মেয়াদ ৬/১২/২৪ ঘণ্টা)
- 💬 কল + **WhatsApp** সরাসরি যোগাযোগ (প্রাইভেসি নিয়ন্ত্রণসহ)
- 🏅 **ডোনেশন হিস্টরি**, ভেরিফাইড ব্যাজ ও টায়ার
- 🔐 অ্যাপMeta-ভিত্তিক **আপডেট নোটিফিকেশন + অ্যাডমিন কন্ট্রোল**
- 📊 ইন-অ্যাপ **ব্যবহার ও কোটা** মনিটরিং (Spark-limits)
